# Vendored BART-base metadata and tokenizer

This directory contains only the configuration and tokenizer assets from
`facebook/bart-base` at revision
`aadd2ab0ae0c8268c7c9693540e9904811f36177`. It does not contain pretrained
model weights. OnomaCap initializes the BART encoder-decoder randomly, matching
the reproduction protocol.
